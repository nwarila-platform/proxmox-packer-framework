# Documentation

This repo follows the Diataxis documentation layout:

- `how-to/` - operational guides (currently minimal).
- `reference/` - the template variable contract, the mirroring model, and the runner protocol.
- `explanation/` - architecture and engineering notes.
- `decision-records/` - org, template, and repo ADRs.

The Packer framework lives under [`../packer/`](../packer/), with example inputs under [`../examples/`](../examples/).
